# SIT Event Compass — Vue.js + Tailwind CSS Performance Lab

This project is designed for teaching Vue.js, Tailwind CSS, UI interactivity, dark mode, reusable components, and build optimization.

## Setup

```bash
npm install
npm run dev
```

## Build optimization demo

```bash
npm run build
npm run preview
npm run analyze
```

## Student tasks

- Inspect `src/style.css`.
- Identify repeated or unused custom classes.
- Run the development server.
- Run the production build.
- Compare asset sizes before and after refactoring.
- Refactor repeated card, button, and badge styles.
- Explain which Tailwind CSS utilities, design tokens, and usability heuristics were applied.
